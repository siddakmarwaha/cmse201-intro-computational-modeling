# CMSE 201 — Intro to Computational Modeling & Data Analysis

![Python](https://img.shields.io/badge/python-3.9%2B-blue) ![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-orange) ![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

First course in MSU's computational modeling sequence: Python fundamentals, data analysis with NumPy and pandas, curve fitting, differential-equation and compartmental (SIR) models, and agent-based models.

**Course:** CMSE 201 — Introduction to Computational Modeling and Data Analysis  
**Term:** Spring 2022  
**Institution:** Michigan State University

## Highlights

- **Final project:** analysis of a year of electronics-store sales — seasonal trends, best-selling products and items frequently bought together.
- Exploratory project on whether soccer players' height and weight relate to their in-game abilities (FIFA player data).
- Conway's Game of Life and agent-based forest-fire models.
